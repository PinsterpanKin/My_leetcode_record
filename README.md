# My LeetCode Record

A collection of LeetCode algorithm solutions, primarily implemented in **python**. This repository serves as a personal laboratory for practicing data structures and algorithm efficiency.

## 📂 Repository Structure

- **`/C`**: Core algorithmic solutions implemented in C. Focuses on manual memory management and pointer logic.
- **`/Python`**: High-level implementations focusing on readability and built-in library usage.
- **`/SQL`**: Database query exercises and optimizations.

## 🛠 Training Stack

- **Primary Language**: Python
- **Environment**: Linux-based development
- **Version Control**: Git

## 🧠 Classic Problem List

This repository follows a classic interview-oriented progression, centered on the well-known Blind 75 problem set and a few additional highly frequent coding challenges.

### Blind 75 Core Topics

- **Array / String**: Two Sum, Best Time to Buy and Sell Stock, Contains Duplicate, Product of Array Except Self, Maximum Subarray, Valid Palindrome, Longest Substring Without Repeating Characters, String to Integer (atoi)
- **Binary Search**: Search in Rotated Sorted Array, Find Minimum in Rotated Sorted Array
- **Linked List**: Reverse Linked List, Merge Two Sorted Lists, Remove Nth Node From End of List, Linked List Cycle, Reorder List
- **Tree / Graph**: Same Tree, Symmetric Tree, Maximum Depth of Binary Tree, Binary Tree Level Order Traversal, Clone Graph, Course Schedule, Number of Islands
- **Dynamic Programming**: House Robber, House Robber II, Longest Palindromic Substring, Word Break, Longest Common Subsequence, Maximum Product Subarray
- **Backtracking / DFS**: Generate Parentheses, Letter Combinations of a Phone Number, Word Search II
- **Heap / Greedy / Sorting**: Kth Largest Element in an Array, Top K Frequent Elements, Merge k Sorted Lists, Container With Most Water

### Additional Classic Interview Problems

- **Data structures**: LRU Cache, Implement Trie, Valid Parentheses
- **Math / Simulation**: Reverse Integer, Palindrome Number, Integer to Roman, Roman to Integer
- **Tree / recursion**: Invert Binary Tree, Construct Binary Tree from Preorder and Inorder Traversal, Convert Sorted Array to Binary Search Tree, Binary Tree Postorder Traversal, Binary Tree Preorder Traversal
- **Graph / BFS / Topological Sort**: Word Ladder, Course Schedule, Clone Graph
- **Advanced patterns**: Regex Matching, Word Break, Copy List with Random Pointer
- **Database / SQL**: classic query exercises for joins, grouping, filtering, and aggregation

These problems are intentionally selected because they cover the most common algorithmic patterns used in technical interviews: two pointers, sliding window, hash maps, stack/queue logic, recursion, greedy choices, dynamic programming, graph traversal, and tree manipulation.

## 📝 Coding Philosophy

- **Efficiency**: Prioritizing $O(n)$ or $O(\log n)$ solutions whenever possible.
- **Robustness**: Handling edge cases (e.g., empty heads in linked lists, single-element arrays).
- **Pythonic & Efficiency**: Actively applying syntactic sugar in python.
- **Clean Code**: Using descriptive variable names and maintaining consistent indentation for C pointers.
